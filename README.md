# Ultradian Focus Timer

A minimalist, single-file focus timer built on the Huberman-style ultradian rhythm protocol: 90-minute deep focus blocks followed by deliberate rest (10-30 min, your choice).

## Features

- 90-minute focus blocks with automatic rest cycles
- Adjustable rest length (10/15/20/30 min)
- Daily cycle tracking with a 3-cycle daily target
- Day streak and lifetime focus hours, saved locally on device
- Built-in 40 Hz binaural beat generator (200 Hz left / 240 Hz right, headphones required)
- Elapsed-time-accurate: keeps counting correctly when the tab is backgrounded
- Phase chime and desktop notifications
- Pure black, Apple/Tesla-style minimal interface

## Use

Open `index.html` in any browser. No build, no server, no internet.

**iPhone/iPad:** open in Safari > Share > Add to Home Screen for a full-screen standalone app.

**Mac/Chrome:** install as app (install icon in the address bar) for a standalone window with its own Dock icon.

## Notes

- History is stored in localStorage per device - pick one device as primary so the streak stays consistent.
- Evidence for binaural-beat focus benefits is mixed; treat it as an A/B test, not a belief.
